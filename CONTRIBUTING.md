# Contributing

VersaVLM is published as a read-only research artifact. The maintainers do not currently promise feature support, board ports, or review of pull requests.

For small documentation or compliance corrections, open an issue before preparing a change. Do not submit model weights, Linux images, Vivado generated directories, bitstreams, XSA files, benchmark logs, credentials, personal paths, or code that you cannot redistribute.

Any accepted contribution must be compatible with Apache-2.0 and retain applicable third-party notices. RTL changes should include the exact tool version, target part, top module, filelist, and validation performed. A successful compile is not evidence of timing closure or board-level correctness.
